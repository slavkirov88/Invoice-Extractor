# TravelInvoices — Демо Видео Guide

**Цел:** 2-минутно демо видео с лице + екран, което показва пълния flow и се качва на сайта + YouTube.

---

## ПРЕДИ ЗАПИС — Подготовка (30 мин)

### OBS Настройки

- [ ] **Стъпка 1: Отвори OBS Studio**

- [ ] **Стъпка 2: Настрой резолюция**
  - Settings → Video
  - Base Resolution: `1920x1080`
  - Output Resolution: `1920x1080`
  - FPS: `30`

- [ ] **Стъпка 3: Настрой качество на запис**
  - Settings → Output → Recording
  - Recording Format: `mp4`
  - Encoder: `x264` (или Hardware ако имаш NVIDIA)
  - Rate Control: `CRF`
  - CRF: `18` (високо качество)
  - Recording Path: избери Desktop или лесна папка

- [ ] **Стъпка 4: Добави "Screen Capture" source**
  - В Sources → натисни `+` → **Display Capture**
  - Име: "Екран"
  - Избери основния монитор
  - Тази source трябва да заема целия екран

- [ ] **Стъпка 5: Добави "Webcam" source**
  - В Sources → натисни `+` → **Video Capture Device**
  - Име: "Камера"
  - Избери уебкамерата
  - Преоразмери до малък кръг/квадрат в долния десен ъгъл (~250x200 px)
  - Десен бутон → Transform → Edit Transform → ако искаш кръгла рамка, потърси OBS plugin "rounded borders"

- [ ] **Стъпка 6: Добави микрофон**
  - Settings → Audio → Mic/Auxiliary Audio: избери микрофона
  - Тествай — говори и гледай нивата в Audio Mixer (трябва да са в зелено/жълто, никога червено)

- [ ] **Стъпка 7: Тествай записа**
  - Натисни "Start Recording" → говори 10 секунди → "Stop Recording"
  - Отвори файла и провери: звук ок? картина ок? камерата вижда ли се?

### Подготовка на приложението

- [ ] **Стъпка 8: Подготви тестови данни**
  - Отвори travelinvoices.com и влез в акаунта
  - Имай готов 1 PDF фактура за демо (реална или тестова)
  - Изтрий тестови протоколи, за да изглежда чисто
  - Създай 1 протокол с 2-3 фактури вече вътре (за да покажеш Раздел В)

- [ ] **Стъпка 9: Подготви браузъра**
  - Затвори всички ненужни табове
  - Скрий bookmarks bar (Ctrl+Shift+B в Chrome)
  - Zoom: 110% за по-добра видимост
  - Изчисти URL бара от предложения

- [ ] **Стъпка 10: Подготви себе си**
  - Облечи тениска/риза с неутрален цвят (без лога/шарки)
  - Светлина на лицето (прозорец или лампа ПРЕД теб, не зад теб)
  - Тих фон (затвори прозорци, изключи телефон)

## СЦЕНАРИЙ (2 минути)

### Въведение (0:00 — 0:20)

**[Камера: Гледаш в камерата, усмихваш се]**

```
"Здравейте! Аз съм Слав и ще ви покажа как TravelInvoices
превръща PDF фактура в готов протокол по маржов метод
за по-малко от 30 секунди.

Ако съставяте протоколи на ръка в Excel —
това ще ви спести часове."
```

**ВАЖНО:**
- Гледай в камерата, не в екрана
- Усмихвай се леко
- Говори бавно и ясно
- Не бързай

### Демо — Качване на фактура (0:20 — 0:50)

**[Екран: Dashboard на приложението]**

```
"Ето приложението. Натискам 'Добави фактура'..."
```

**[Действие: Натисни бутона, drag-and-drop PDF файл]**

```
"...и просто пускам PDF-а. Толкова."
```

**[Екран: AI извлича данни — покажи loading и резултата]**

```
"AI-ят автоматично разпознава номера на документа,
датата и стойността. Нищо не трябва да пиша на ръка."
```

**ВАЖНО:**
- Движи мишката бавно — зрителят трябва да следи
- Изчакай 1-2 секунди след всяко действие

### Демо — Протокол (0:50 — 1:20)

**[Действие: Избери протокол, избери тип (приходна/разходна), добави]**

```
"Избирам протокол, посочвам тип — приходна за Раздел А
или разходна за Раздел Б. Натискам 'Добави'. Готово."
```

**[Екран: Отвори протокола — покажи Раздел А, Б, В]**

```
"Да видим протокола. Ето Раздел А с получените фактури,
Раздел Б с платените, и най-важното — Раздел В.
Маржът, данъчната основа и ДДС
са изчислени автоматично. Без калкулатор."
```

**ВАЖНО:**
- Задръж на Раздел В 3-4 секунди — това е hero момента
- Посочи с мишката числата

### Демо — Експорт (1:20 — 1:40)

**[Действие: Натисни Export → Excel или PDF]**

```
"С едно кликване го експортвам в Excel или PDF —
готов за счетоводителя или за НАП."
```

### Заключение (1:40 — 2:00)

**[Камера: Отново гледаш в камерата]**

```
"Това е. От PDF фактура до готов протокол — 30 секунди.
Вместо 15 часа месечно — под 1 час.

Пробвайте 14 дни безплатно на travelinvoices.com.
Без карта, без ангажимент. Линкът е в описанието."
```

**[Усмивка, кимване]**

## СЪВЕТИ ЗА ПЕРФЕКТНО ВИДЕО

1. **Запиши го 3 пъти** — първия път ще е скован, третия ще е естествен
2. **Не чети от екрана** — запомни основните точки, говори естествено
3. **Говори като на приятел** — не като презентация, а като показваш нещо на колега
4. **Бавна мишка** — зрителят трябва да може да следи какво правиш
5. **Паузи** — след всяко важно действие изчакай 1-2 секунди
6. **Усмивка** — когато гледаш в камерата, усмихвай се леко
7. **Дължина: 1:30 — 2:30** — не повече. Хората спират след 2 минути
8. **Фон звук** — НЕ слагай музика. Чист звук, само глас.
